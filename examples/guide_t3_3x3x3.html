1. Bill of materials

Counts are AE2 parts and blocks. Their crafting cost depends on your pack's recipes (check JEI). Use fluix (uncoloured) cables unless noted.

2. Build it layer by layer

  1. Start at layer 0 and work up. On each layer, place the cable cells first, with all their parts, then the controllers.
  2. Put each part on the side shown. Hold the part and right-click that side of the cable, or right-click the neighbouring controller's face.
  3. Parts on a cell's up side face the next layer: place them before you build that layer.
  4. Every controller face next to a cable cell needs a part: a tunnel or a cable anchor. A missing anchor merges the two networks.
  5. Exit sides stay open. That's where your tunnel network's cable connects.

3. Link the input tunnels

Each input carries one controller face's channels () to its output. Shift-right-click an input with a Memory Card to store its frequency, then right-click the output tunnel (where you want the channels) to link it. Tick each input when it's done: ticks are saved in this browser.
