# In-game validation checklist

Generated by `python -m ae2opt export-tests`. Profile: Default (8/32/7x7x7) (normal 8, dense 32, controller size 7x7x7). Your AE2 config must match. Works with plain AE2 rv6 and with Extended Life.

**Goal:** check that the game shows exactly what the simulator predicts. A single mismatch means the model is wrong somewhere, and optimizer results can't be trusted until it's fixed. Note *what* differs: that tells us which rule is off.

## You need

- **WAILA/HWYLA or The One Probe.** AE2 adds channel info to both:
  - a smart cable shows `X of 8 Channels`; a dense smart cable shows `X of 32 Channels`. The number is that cable's busiest side.
  - a P2P tunnel or ME terminal shows `Device Online` (powered, has a channel) or `Device Missing Channel`.
- **F3**, to read the coordinates of the block you're looking at (`Looking at: x y z`).

## Setup (once per test)

1. Copy every `ae2opt_*.nbt` from this folder into `saves/<world>/structures/` (create the folder if needed).
2. In a creative superflat world, place a structure block (`/give @p minecraft:structure_block`), set it to **Load**, and enter the name (for example `ae2opt_t1`). Leave the offset at 0 1 0. Click **Load** twice.
3. Write down the structure block's position **S**. A block listed below at `rel (a, b, c)` is at world position **S + (a, 1 + b, c)**.
4. Wait about 5 seconds for both networks to boot.

## What's in a positive test

- **The build:** main controllers, plus cable cells with input tunnels and cable anchors.
- **Collector:** a few separate trees of dense smart cable, two or three blocks out from the build, leading down from the build's exits. Each tree ends in one **collector root** cable sitting directly on a controller below.
- **Tunnel-network controller:** a snake of controllers under everything, with a creative energy cell under its corner.
- **Main power:** one creative energy cell touching a main controller.
- **Two output rigs on top:** an output tunnel, then a vertical dense smart cable with 40 ME terminals around it.

**The main pass/fail check is the collector roots.** Every active tunnel uses one tunnel-network channel. Each tree carries all of its tunnels down to its root, so the roots' readings must add up to the tunnel count. Tunnels hidden inside a build are counted too.
